# navplate-food-tracker

NavPlate is a food tracking application specifically designed for people with disordered eating, eating disorders, and other food-related disorders. This application is currently a proof of concept and we plan on improving it in the future.  
  
It is made to be highly configurable so the user can choose to see calories, macros, and other nutrition metrics. It gives the user full control over what they see so they can still track their foods everyday without the worry of seeing information that might be triggering.  

This application uses a React Native frontend with .NET and a C# backend. It uses a MySQL database to store the food data and the user-inputted information. In order for the app to function end-to-end, it needs to have access configured to the database.

Again, this application is just a proof of concept currently. We plan on improving the visuals, adding a cooldown timer when a user wants to change a configuration (waiting 24 hours to see calories/macros/etc. after clicking to see it), containerizing the frontend and backend, and migrating the database to somewhere more permanent.
